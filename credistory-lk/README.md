# Кабинет Арины · Рефинансирование · прототип v2

Откройте `index.html` в браузере. Сборка и сервер не нужны.

```
index.html   разметка
styles.css   токены Кредистории (#4C33E4), компоненты, адаптив 1080 / 760 px
app.js       расчёт экономии, точки входа, флоу запроса в банки
data.js      демо-данные клиента и банков — заменяются на API
```

## Что изменилось в v2
- **Первый экран — экономия.** «Можно платить на 60 тыс ₽ меньше в месяц» и переключатель цели: снизить платёж / переплатить меньше / получить деньги сверху. Выбор кредитов для объединения, срок, сумма сверху. Всегда видны платёж, ставка, срок, проценты, количество кредитов и ПДН «сейчас / после». Если переплата растёт — предупреждение.
- **Предложения банков (US-2).** Предодобрения с экономией по каждому банку. Неподходящие приглушены с причиной.
- **Точки входа (US-1).** В «Моих кредитах» у дорогих кредитов метка «−X ₽/мес · Посчитать».
- **Флоу запроса (US-3, шаги 3.1–3.6):** проверка данных и согласие → «Ответили N из M» со статусами банков → выбор с меткой «Выгоднее всего» → переход к партнёру со ссылкой с UTM и lead_id. Отдельный экран «Банки пока не одобрили» с планом действий.
- **«Мои заявки»** показывают статус запроса; окно ожидания можно закрыть.

## Сценарии в демо-полосе
- **Есть предодобрения** — расчёт по лучшему предодобрению.
- **Без предодобрений, запрос по API** — расчёт по рыночной ставке 17,5 %, блок «Узнайте условия в 6 банках».
- **Все банки отказали** — сценарий отказа.

## Допущения
Предодобрения, ставки банков и рыночная ставка — демо-значения. Цвет #4C33E4 взят с credistory.ru, остальные токены подобраны по виду сайта.
