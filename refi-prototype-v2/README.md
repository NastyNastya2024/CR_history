# Кабинет Арины · Рефинансирование · прототип v2 с входом по паролю

Статический прототип личного кабинета Кредистории. Сборка, сервер и база не нужны: файлы можно выложить на любой хостинг статики или открыть `index.html` с диска.

## Вход
- Пароль по умолчанию: **Refi-Arina-2026**
- Галочка «Запомнить на этом устройстве» сохраняет вход на 7 дней. Без неё вход действует до закрытия вкладки.
- Выйти: аватар в правом верхнем углу → «Выйти».
- После 5 неверных попыток вход блокируется на 30 секунд.

## Как сменить пароль
1. Откройте `set-password.html` в браузере, введите новый пароль дважды (от 8 символов).
2. Скопируйте полученную строку.
3. В файле `auth.js` замените значение `PASSWORD_HASH` на эту строку и сохраните.
4. Выложите файлы заново. Старые сохранённые входы перестанут работать.

`set-password.html` — служебная страница. После смены пароля её можно не выкладывать на хостинг.

## Как опубликовать
Залейте содержимое папки целиком (без `screenshots/` по желанию) на любой хостинг статики:
- GitHub Pages, GitLab Pages — загрузите файлы в репозиторий и включите Pages;
- Netlify Drop, Vercel, Cloudflare Pages — перетащите папку или архив;
- корпоративный веб-сервер — положите файлы в каталог сайта.

Страница не индексируется поисковиками (`noindex`).

## Насколько надёжна защита
Пароль проверяется в браузере по хешу SHA-256 с солью; сам пароль в файлах не хранится. Это защищает от случайных посетителей и поисковиков, но не от человека, который откроет исходный код страницы: демо-данные лежат в `data.js`. В прототипе нет реальных персональных данных, поэтому для показа этого достаточно.

Если понадобится серверная защита, включите пароль средствами хостинга: Password Protection в Vercel или Netlify, Cloudflare Access, либо Basic Auth на nginx/Apache. Код прототипа менять не нужно.

```
data.js            демо-данные клиента и банков
styles.css         стили в духе Кредистории (#4C33E4), адаптив 1080 / 760 px
set-password.html  служебная страница для смены пароля
screenshots/       скриншоты десктопа, мобильной версии и флоу
```
